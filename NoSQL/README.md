# NoSQL

MongoDB basics with the `mongo` shell and with Python (`pymongo`).

| File | Description |
| --- | --- |
| `0-list_databases` | Lists all databases |
| `1-use_or_create_database` | Creates or switches to `my_db` |
| `2-insert` | Inserts `{ name: "Holberton school" }` in `school` |
| `3-all` | Lists all documents in `school` |
| `4-match` | Lists documents with `name="Holberton school"` |
| `5-count` | Counts the documents in `school` |
| `6-update` | Adds `address: "972 Mission street"` to matching documents |
| `7-delete` | Deletes documents with `name="Holberton school"` |
| `8-all.py` | `list_all(mongo_collection)` |
| `9-insert_school.py` | `insert_school(mongo_collection, **kwargs)` |
| `10-update_topics.py` | `update_topics(mongo_collection, name, topics)` |
| `11-schools_by_topic.py` | `schools_by_topic(mongo_collection, topic)` |
| `12-log_stats.py` | Prints stats about the `logs.nginx` collection |
